## 1. nn.Module - 神经网络的基石

### 1.1 核心功能

`nn.Module` 是PyTorch中所有神经网络的基类，提供了以下关键功能：

| 功能 | 说明 |
|------|------|
| 参数管理 | 自动追踪所有可学习的 `nn.Parameter` |
| GPU加速 | 一键通过 `.to(device)` 转移模型到GPU |
| 保存加载 | 支持 `state_dict()` 保存和加载模型参数 |
| 模块化 | 可以像搭积木一样嵌套组合 |

### 1.2 使用模板

```python
class MyModel(nn.Module):
    def __init__(self):
        super(MyModel, self).__init__()
        # 在这里定义层
        self.layer1 = nn.Linear(784, 256)
        self.relu = nn.ReLU()
        self.layer2 = nn.Linear(256, 10)
    
    def forward(self, x):
        # 在这里定义前向传播
        x = self.layer1(x)
        x = self.relu(x)
        x = self.layer2(x)
        return x
```

### 1.3 重要方法

```python
model = MyModel()

# 查看模型结构
print(model)

# 查看所有参数
for name, param in model.named_parameters():
    print(f"{name}: {param.shape}")

# 统计参数量
total = sum(p.numel() for p in model.parameters())
print(f"总参数量: {total:,}")

# 移到GPU
model = model.to('mps')  # 或 'cuda', 'cpu'

# 保存/加载
model.save('model.pth')
model.load_state_dict(torch.load('model.pth'))
```

## 2. 激活函数

### 2.1 为什么需要激活函数？

**没有激活函数 = 多层网络 = 单层线性变换**

```
Linear(Linear(x)) = W2 @ (W1 @ x + b1) + b2
                  = (W2 @ W1) @ x + (W2 @ b1 + b2)
                  = W' @ x + b'  ← 仍然是线性！
```

激活函数引入非线性，让网络可以学习复杂的模式。

### 2.2 常用激活函数对比

| 激活函数 | 公式 | 输出范围 | 特点 | 使用场景 |
|---------|------|---------|------|---------|
| **ReLU** | max(0, x) | [0, +∞) | 简单高效，缓解梯度消失 | **默认首选** |
| **GELU** | x·Φ(x) | (-∞, +∞) | 更平滑，Transformer常用 | BERT/GPT |
| **Sigmoid** | 1/(1+e^(-x)) | (0, 1) | 输出概率，有梯度消失问题 | 二分类输出层 |
| **Tanh** | (e^x - e^(-x))/(e^x + e^(-x)) | (-1, 1) | 以0为中心，仍有梯度消失 | RNN隐藏层 |
| **LeakyReLU** | max(αx, x) | (-∞, +∞) | 解决"死亡ReLU"问题 | ReLU的替代 |

### 2.3 使用建议

```python
# 隐藏层：ReLU（默认）
nn.ReLU()  # 或 nn.LeakyReLU(), nn.GELU()

# 输出层：
nn.Sigmoid()    # 二分类
# 不加激活函数   # 多分类（配合CrossEntropyLoss自动加Softmax）
```

## 3. 多层感知机（MLP）

### 3.1 结构示意图

```
输入层          隐藏层1         隐藏层2         输出层
 784           256             128            10
   ●────┐         ●              ●              ●
   ●    ├─────────●──────────────●──────────────●
   ●────┘    ↑    ●    ↑         ●              ●
   ●      Linear  ReLU       Linear           Linear
   ●      +Bias   +Dropout   +ReLU            (原始分数)
   ●
  ...
```

### 3.2 完整实现

```python
class MLP(nn.Module):
    def __init__(self, input_size=784, hidden1=256, hidden2=128, num_classes=10):
        super(MLP, self).__init__()
        
        self.layer1 = nn.Linear(input_size, hidden1)
        self.relu1 = nn.ReLU()
        self.dropout1 = nn.Dropout(0.2)  # 20%随机置零
        
        self.layer2 = nn.Linear(hidden1, hidden2)
        self.relu2 = nn.ReLU()
        self.dropout2 = nn.Dropout(0.2)
        
        self.layer3 = nn.Linear(hidden2, num_classes)
    
    def forward(self, x):
        x = self.layer1(x)
        x = self.relu1(x)
        x = self.dropout1(x)
        
        x = self.layer2(x)
        x = self.relu2(x)
        x = self.dropout2(x)
        
        x = self.layer3(x)
        return x
```

## 4. 损失函数

### 4.1 回归问题

| 损失函数 | 公式 | 特点 |
|---------|------|------|
| MSELoss | mean((y_pred - y)^2) | 对大误差惩罚重 |
| L1Loss | mean(\|y_pred - y\|) | 对异常值更鲁棒 |
| SmoothL1Loss | Huber损失 | 结合MSE和L1的优点 |

### 4.2 分类问题

**CrossEntropyLoss = Softmax + 负对数似然**

```python
# 输入：原始分数（logits）
logits = torch.tensor([[2.0, 1.0, 0.1]])
labels = torch.tensor([0])  # 真实类别是0

# CrossEntropyLoss自动：
# 1. 对logits应用Softmax得到概率
probs = torch.softmax(logits, dim=1)  # [0.7, 0.2, 0.1]

# 2. 取真实类别的概率的对数的负数
loss = -log(probs[0, 0])  # -log(0.7) ≈ 0.36
```

### 4.3 使用示例

```python
# 回归
pred = model(x)  # [batch, 1]
target = y       # [batch, 1]
loss = nn.MSELoss()(pred, target)

# 多分类
pred = model(x)     # [batch, num_classes] - 原始分数
target = labels     # [batch] - 类别索引
loss = nn.CrossEntropyLoss()(pred, target)

# 二分类
pred = model(x)     # [batch, 1] - 经过Sigmoid的概率
target = labels     # [batch, 1] - 0或1
loss = nn.BCELoss()(pred, target)
```

## 5. 优化器

### 5.1 优化器对比

| 优化器 | 学习率 | 动量/自适应 | 适用场景 |
|-------|--------|-----------|---------|
| SGD | 固定 | 无 | 简单问题，需要精细调参 |
| SGD+Momentum | 固定 | 动量 | 加速收敛，跳过局部最优 |
| **Adam** | **自适应** | 一阶+二阶矩 | **通用首选** |
| **AdamW** | **自适应** | +权重衰减 | **Transformer训练首选** |

### 5.2 学习率设置

```python
# SGD: 较大学习率
optim.SGD(model.parameters(), lr=0.01)  # 0.001 ~ 0.1

# Adam: 较小学习率
optim.Adam(model.parameters(), lr=0.001)  # 常用: 1e-4, 3e-4, 1e-3

# AdamW: 带权重衰减（正则化）
optim.AdamW(model.parameters(), lr=1e-4, weight_decay=0.01)
```

### 5.3 学习率调度

```python
from torch.optim.lr_scheduler import StepLR, CosineAnnealingLR

# 每10个epoch学习率衰减为原来的0.1
scheduler = StepLR(optimizer, step_size=10, gamma=0.1)

# 余弦退火
scheduler = CosineAnnealingLR(optimizer, T_max=100)

# 训练循环中使用
for epoch in range(epochs):
    train(...)
    scheduler.step()  # 更新学习率
```

## 6. 完整训练流程

### 6.1 训练循环模板

```python
# 1. 准备
model = MyModel().to(device)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 2. 训练
for epoch in range(n_epochs):
    model.train()  # 训练模式
    
    for batch_x, batch_y in dataloader:
        # 数据移到GPU
        batch_x = batch_x.to(device)
        batch_y = batch_y.to(device)
        
        # 前向传播
        outputs = model(batch_x)
        loss = criterion(outputs, batch_y)
        
        # 反向传播
        optimizer.zero_grad()   # 清空梯度
        loss.backward()         # 计算梯度
        optimizer.step()        # 更新参数
    
    # 验证
    model.eval()  # 评估模式
    with torch.no_grad():
        # 计算验证集准确率
        ...
```

### 6.2 train() vs eval()

| 模式 | 作用 | 何时使用 |
|------|------|---------|
| `model.train()` | 启用Dropout、BatchNorm更新 | 训练时 |
| `model.eval()` | 禁用Dropout、使用运行统计的BN | 验证/测试时 |

### 6.3 torch.no_grad()

```python
# 评估时不需要计算梯度，节省内存和时间
with torch.no_grad():
    predictions = model(test_data)
    # 这里不记录计算图
```

## 8. 模型保存与加载

### 8.1 推荐方式：只保存参数

```python
# 保存
model_path = 'model.pth'
torch.save(model.state_dict(), model_path)

# 加载（需要先创建模型实例）
model = MyModel()  # 创建相同结构的模型
model.load_state_dict(torch.load(model_path))
model.eval()  # 切换到评估模式
```

### 8.2 保存完整checkpoint

```python
# 保存（包含优化器状态，可以恢复训练）
checkpoint = {
    'epoch': epoch,
    'model_state_dict': model.state_dict(),
    'optimizer_state_dict': optimizer.state_dict(),
    'loss': loss,
}
torch.save(checkpoint, 'checkpoint.pth')

# 加载
checkpoint = torch.load('checkpoint.pth')
model.load_state_dict(checkpoint['model_state_dict'])
optimizer.load_state_dict(checkpoint['optimizer_state_dict'])
start_epoch = checkpoint['epoch']
```

## 9. 今日要点总结

### 9.1 核心公式

```
神经网络前向传播:  y = σ(W·x + b)
                  ↓ σ是激活函数
交叉熵损失:       L = -Σ y_true · log(softmax(y_pred))
                  ↓
反向传播:        ∂L/∂W = ...
                  ↓
参数更新:        W = W - lr · ∂L/∂W
```

### 9.2 速查表

| 组件 | 常用选择 | 代码 |
|-----|--------|------|
| 层 | Linear | `nn.Linear(in, out)` |
| 激活函数 | ReLU/GELU | `nn.ReLU()` / `nn.GELU()` |
| 正则化 | Dropout | `nn.Dropout(0.2)` |
| 损失-分类 | CrossEntropy | `nn.CrossEntropyLoss()` |
| 损失-回归 | MSE | `nn.MSELoss()` |
| 优化器 | Adam | `optim.Adam(model.parameters(), lr=0.001)` |
| GPU转移 | to() | `model.to(device)` |
