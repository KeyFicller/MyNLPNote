## 1. 文本预处理流程

### 1.1 为什么需要预处理？

**原始文本的问题**：
- 大小写不统一
- 包含HTML标签、URL、邮箱
- 特殊符号、表情、多余空格
- 全角/半角不统一

**标准预处理流程**：

```
原始文本
    ↓
去除噪声（HTML、URL、邮箱、特殊符号）
    ↓
规范化（统一大小写、全角转半角）
    ↓
分词（中文需分词工具）
    ↓
去除停用词（可选）
    ↓
干净的token序列
```

### 1.2 预处理代码模板

```python
import re

def clean_text(text):
    """文本清洗函数"""
    # 去除HTML标签
    text = re.sub(r'<[^>]+>', '', text)
    
    # 去除URL
    text = re.sub(r'http[s]?://\S+', '', text)
    
    # 去除邮箱
    text = re.sub(r'\S+@\S+', '', text)
    
    # 去除特殊符号，保留中英文和数字
    text = re.sub(r'[^\u4e00-\u9fa5a-zA-Z0-9\s]', ' ', text)
    
    # 去除多余空格
    text = ' '.join(text.split())
    
    # 统一小写
    text = text.lower()
    
    return text
```

## 2. 中文分词

### 2.1 中文分词的难点

| 特点 | 中文 | 英文 |
|-----|------|------|
| 分隔符 | 无空格 | 有空格 |
| 歧义 | 多（"南京市长江大桥"） | 少 |
| 新词 | 持续产生 | 相对稳定 |
| 工具 | 必需 | 简单split即可 |

**歧义示例**：
```
"南京市长江大桥"
- 南京市 / 长江大桥（地名+建筑）
- 南京 / 市长 / 江大桥（城市+职务+人名）
```

### 2.2 常用分词工具

| 工具 | 特点 | 适用场景 |
|-----|------|---------|
| **jieba** | 最流行，分词速度快 | 通用场景首选 |
| **HanLP** | 功能丰富，准确率高 | 学术、专业场景 |
| **pkuseg** | 北大出品，领域适应好 | 专业领域文本 |
| **THULAC** | 清华出品，C++实现 | 对速度要求高 |

### 2.3 jieba使用示例

```python
import jieba

# 基础分词
text = "我爱自然语言处理"
words = jieba.lcut(text)
# ['我', '爱', '自然语言', '处理']

# 全模式（所有可能的分词）
words = jieba.lcut(text, cut_all=True)

# 搜索引擎模式（更细粒度）
words = jieba.lcut_for_search(text)

# 添加自定义词典
jieba.add_word('机器学习')
```

## 3. 词表示方法

### 3.1 One-hot编码

```python
vocab = ["猫", "狗", "鱼", "鸟"]

# One-hot表示
猫 = [1, 0, 0, 0]  # 4维
狗 = [0, 1, 0, 0]  # 4维
鱼 = [0, 0, 1, 0]  # 4维
鸟 = [0, 0, 0, 1]  # 4维
```

**缺点**：
- 维度灾难：10万词 = 10万维
- 稀疏性：每个向量只有一个1
- 无语义：无法计算词与词的相似度

### 3.2 词嵌入（Word Embedding）

```python
# 稠密向量表示（通常50-300维）
猫 = [0.2, -0.5, 0.8, 0.1, -0.3]  # 5维
狗 = [0.3, -0.4, 0.9, 0.2, -0.2]  # 相似！
鱼 = [-0.8, 0.2, 0.1, 0.9, 0.5]   # 不同！
```

**优点**：
- 低维度：通常50-300维
- 语义相似度可计算
- 支持向量运算

## 4. Word2Vec原理

### 4.1 核心思想

**"一个词的含义由它的上下文决定"** —— 分布假说

### 4.2 两种训练方式

#### CBOW (Continuous Bag of Words)

```
上下文 → 预测中心词

输入：["我", "喜欢", "___", "技术"]
           ↓
        神经网络
           ↓
输出："深度"（中心词）
```

#### Skip-gram（更常用）

```
中心词 → 预测上下文

输入："深度"
           ↓
        神经网络
           ↓
输出：["我", "喜欢", "学习", "技术"]（上下文）
```

### 4.3 训练过程

```python
# 伪代码
for epoch in range(num_epochs):
    for sentence in corpus:
        # 滑动窗口获取(中心词, 上下文)对
        for center_word, context_words in get_pairs(sentence):
            # 前向传播：预测上下文
            predicted = model(center_word)
            
            # 计算损失
            loss = cross_entropy(predicted, context_words)
            
            # 反向传播，更新词向量
            loss.backward()
            optimizer.step()
```

### 4.4 负采样（Negative Sampling）

为了加速训练，不预测所有词，而是：
- 预测真实上下文词（正样本）
- 随机采样几个非上下文词（负样本）
- 优化：区分正样本和负样本

## 5. 词向量的神奇性质

### 5.1 词向量算术

| 运算 | 结果 | 解释 |
|-----|------|------|
| King - Man + Woman | ≈ Queen | 性别关系 |
| Paris - France + Italy | ≈ Rome | 首都-国家关系 |
| 中国 - 北京 + 东京 | ≈ 日本 | 类似关系 |
| 跑步 - 跑 + 吃 | ≈ 吃饭 | 动词-名词关系 |

### 5.2 语义相似度计算

```python
import numpy as np

def cosine_similarity(v1, v2):
    """余弦相似度：-1到1之间"""
    return np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))

# 相似度高
cosine_similarity(vec("猫"), vec("狗"))  # ≈ 0.8

# 相似度低
cosine_similarity(vec("猫"), vec("苹果"))  # ≈ 0.1
```

## 6. PyTorch中的词嵌入

### 6.1 nn.Embedding

```python
import torch.nn as nn

# 创建嵌入层
embedding = nn.Embedding(
    num_embeddings=10000,  # 词典大小
    embedding_dim=300,     # 向量维度（通常100-300）
    padding_idx=0          # 填充词的ID

# 使用：输入词ID，输出词向量
word_ids = torch.LongTensor([1, 5, 10, 42])  # 4个词
word_vectors = embedding(word_ids)  # [4, 300]
```

## 7. 词嵌入的演进

| 模型 | 年份 | 特点 |
|-----|------|------|
| Word2Vec | 2013 | 静态词向量，上下文无关 |
| GloVe | 2014 | 基于全局统计+局部窗口 |
| FastText | 2016 | 考虑子词（n-gram），解决OOV问题 |
| ELMo | 2018 | 动态词向量，上下文相关（RNN） |
| BERT/GPT | 2018+ | 上下文相关（Transformer），NLP新时代 |

**OOV问题**：Out-of-Vocabulary，词典中没有的词
- Word2Vec/GloVe：无法处理
- FastText：通过子词向量组合
- BERT：通过字符级表示
