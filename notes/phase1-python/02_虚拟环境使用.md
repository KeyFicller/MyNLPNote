# 虚拟环境使用指南

## 什么是虚拟环境？

虚拟环境是一个独立的Python运行环境，可以：
- 隔离项目依赖（不同项目用不同版本库）
- 保持系统Python干净
- 方便分享和部署

## 常用命令

### 激活虚拟环境

**macOS/Linux:**
```bash
source venv/bin/activate
# 或者使用我提供的脚本
source activate_env.sh
```

**Windows:**
```cmd
venv\Scripts\activate
```

### 退出虚拟环境
```bash
deactivate
```

### 安装依赖
```bash
# 安装单个包
pip install numpy

# 安装requirements.txt中所有依赖
pip install -r requirements.txt
```

### 保存当前依赖
```bash
pip freeze > requirements.txt
```

## 验证虚拟环境

激活后，运行以下命令查看Python路径：
```bash
which python
```

应该显示类似：`/Users/keyficller/Documents/AllInAI/venv/bin/python`

## 学习流程

1. 打开终端，进入项目目录
2. 运行 `source activate_env.sh` 激活环境
3. 开始学习/运行代码
4. 学完运行 `deactivate` 退出

## 注意事项

- ✅ 每次学习前激活虚拟环境
- ✅ 安装新库前确认环境已激活
- ❌ 不要把 `venv` 文件夹提交到Git
