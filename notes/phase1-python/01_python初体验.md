## 今日笔记

### 1. print() 函数
print() 是Python最常用的函数，用来输出内容到屏幕。

```python
print("要输出的内容")
```

### 2. 变量
变量就是用来存储数据的容器，不需要提前声明类型。

```python
name = "小明"      # 字符串
age = 25         # 整数
price = 19.99    # 浮点数
```

### 3. 字符串
- 可以用单引号 `'...'` 或双引号 `"..."`
- 拼接用 `+` 号
- 格式化推荐用 f-string：`f"...{变量}..."`
