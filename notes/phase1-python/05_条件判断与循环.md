## 今日笔记

### 1. 条件判断

```python
# 基础 if-else
if score >= 60:
    print("及格")
else:
    print("不及格")

# if-elif-else 多条件
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "D"

# 三元表达式
status = "成年" if age >= 18 else "未成年"
```

### 2. for 循环

```python
# 遍历列表
for item in list:
    print(item)

# range()
for i in range(5):        # 0,1,2,3,4
for i in range(1, 6):    # 1,2,3,4,5
for i in range(0, 10, 2): # 0,2,4,6,8

# enumerate - 带索引
for i, item in enumerate(list, start=1):
    print(i, item)

# zip - 并行遍历
for a, b in zip(list1, list2):
    print(a, b)
```

### 3. while 循环

```python
while condition:
    # 循环体
    # 注意要有终止条件，避免死循环
```

### 4. 循环控制

| 关键字 | 作用 |
|--------|------|
| `break` | 跳出整个循环 |
| `continue` | 跳过当前迭代，继续下一次 |
| `pass` | 占位符，什么都不做 |

### 5. 列表推导式

```python
# 基础
[x**2 for x in range(5)]

# 带条件
[x for x in range(10) if x % 2 == 0]

# if-else 在推导式中
["偶数" if x % 2 == 0 else "奇数" for x in range(5)]

# 字典推导式
{k: v for k, v in zip(keys, values)}

# 集合推导式
{x for x in list}
```
