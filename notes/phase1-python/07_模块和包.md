## 今日笔记

### 1. 导入模块的4种方式

```python
# 方式1：导入整个模块
import math
math.sqrt(16)  # 4.0

# 方式2：从模块导入特定内容
from math import sqrt, pi
sqrt(16)  # 直接使用，不需要 math.

# 方式3：使用别名
import numpy as np
from datetime import datetime as dt

# 方式4：导入所有（不推荐）
from math import *  # 容易命名冲突
```

### 2. 常用标准库模块

| 模块 | 用途 | 常用功能 |
|------|------|----------|
| `os` | 操作系统 | `os.path.join()`, `os.getcwd()` |
| `sys` | 系统信息 | `sys.version`, `sys.argv` |
| `random` | 随机数 | `random.randint()`, `random.choice()` |
| `datetime` | 日期时间 | `datetime.now()`, `timedelta` |
| `json` | JSON处理 | `json.dumps()`, `json.loads()` |
| `re` | 正则表达式 | `re.findall()`, `re.match()` |
| `collections` | 高级数据结构 | `Counter`, `defaultdict` |
| `math` | 数学运算 | `math.sqrt()`, `math.pi` |
| `pathlib` | 路径处理 | `Path()`, `path.exists()` |
| `logging` | 日志记录 | `logging.info()`, `logging.warning()` |

### 3. 自定义模块

```python
# my_utils.py（模块文件）
def greet(name):
    return f"你好，{name}！"

PI = 3.14159

# main.py（使用模块）
import my_utils
print(my_utils.greet("小明"))
```

### 4. 包的结构

```
my_package/          ← 包文件夹
├── __init__.py      ← 必须有（可以为空）
├── module1.py
└── module2.py

使用：from my_package import module1
```

### 5. __name__ 的作用

```python
def main():
    # 主程序逻辑
    pass

if __name__ == "__main__":
    main()
```

- 直接运行文件：`__name__ == "__main__"`
- 作为模块导入：`__name__ == "模块名"`
