## 今日笔记

### 1. 数字类型

| 类型 | 示例 | 说明 |
|------|------|------|
| int | `25`, `1000000` | 整数，可大至无限 |
| float | `1.75`, `3.14` | 浮点数（小数） |
| complex | `3+4j` | 复数（了解即可） |

### 2. 字符串

```python
text = "Hello"
# 常用方法
len(text)      # 长度
text.strip()   # 去空格
text.upper()   # 转大写
text.lower()   # 转小写
text[0:3]      # 切片，取前3个字符
```

### 3. 布尔值

```python
True, False
# 运算
True and False  # False
True or False   # True
not True        # False
```

### 4. 运算符速查

| 类别 | 符号 | 示例 | 结果 |
|------|------|------|------|
| 算术 | `+ - * /` | `10 / 3` | `3.333...` |
| 算术 | `//` | `10 // 3` | `3`（整除） |
| 算术 | `%` | `10 % 3` | `1`（取余） |
| 算术 | `**` | `2 ** 3` | `8`（幂） |
| 比较 | `== != > < >= <=` | `5 == 5` | `True` |
| 赋值 | `+= -= *= /=` | `x += 5` | `x = x + 5` |
| 逻辑 | `and or not` | `True and False` | `False` |

### 5. 类型转换

```python
int("100")     # 字符串转整数
float("3.14")  # 字符串转浮点数
str(42)        # 数字转字符串
```

**注意**：`int("hello")` 会报错！
