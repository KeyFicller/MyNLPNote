## 今日笔记

### 1. 函数基础

```python
# 定义函数
def greet(name):
    """文档字符串（说明函数功能）"""
    print(f"你好，{name}！")

# 调用函数
greet("小明")

# 返回值
def add(a, b):
    return a + b

result = add(1, 2)  # result = 3
```

### 2. 参数类型

```python
# 位置参数
def func(a, b):
    pass
func(1, 2)  # a=1, b=2

# 关键字参数
func(b=2, a=1)  # 顺序不重要

# 默认参数
def func(a, b=10):  # b有默认值
    pass

# 可变参数 *args（接收任意数量的位置参数）
def func(*args):
    # args 是元组
    pass
func(1, 2, 3)

# 可变参数 **kwargs（接收任意数量的关键字参数）
def func(**kwargs):
    # kwargs 是字典
    pass
func(a=1, b=2)
```

### 3. 作用域

```python
global_var = "全局变量"

def func():
    local_var = "局部变量"  # 只在函数内有效
    print(global_var)  # 可以访问全局变量
    
    # 修改全局变量需要 global 关键字
    global global_var
    global_var = "修改了"

# 推荐：避免使用 global，通过参数和返回值传递数据
```

### 4. Lambda 表达式

```python
# 语法：lambda 参数: 返回值
square = lambda x: x ** 2

# 常用场景
map(lambda x: x**2, [1, 2, 3])      # [1, 4, 9]
filter(lambda x: x>0, [-1, 1, 2])   # [1, 2]
sorted(list, key=lambda x: x[1])     # 按第二个元素排序
```

### 5. 类型提示（现代Python推荐）

```python
def add(a: int, b: int) -> int:
    """求和函数"""
    return a + b
```

| 符号 | 含义 |
|------|------|
| `x: int` | 参数x应为整数 |
| `-> float` | 返回值应为浮点数 |
| `List[int]` | 整数列表 |
| `Dict[str, int]` | 字符串到整数的字典 |
| `Optional[str]` | 字符串或None |
