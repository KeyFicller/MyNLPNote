## 今日笔记

### 1. 列表（List）

```python
# 创建
fruits = ["苹果", "香蕉", "橙子"]

# 访问（索引从0开始）
fruits[0]    # 第一个
fruits[-1]   # 最后一个

# 切片 [start:end] 左闭右开
fruits[0:2]  # 第1、2个
fruits[::-1] # 反转
```

**常用方法：**

| 方法 | 作用 | 示例 |
|------|------|------|
| append(x) | 末尾添加 | `list.append(5)` |
| insert(i, x) | 指定位置插入 | `list.insert(1, 5)` |
| pop() | 删除并返回末尾 | `list.pop()` |
| remove(x) | 删除第一个x | `list.remove(5)` |
| sort() | 原地排序 | `list.sort()` |
| len(list) | 长度 | `len(list)` |

### 2. 字典（Dictionary）

```python
# 创建
student = {"name": "小明", "age": 20}

# 访问
student["name"]          # 直接访问（不存在会报错）
student.get("name")      # get方法（不存在返回None）
student.get("xxx", "默认") # 提供默认值

# 添加/修改
student["hobby"] = "编程"  # 添加
student["age"] = 21       # 修改

# 删除
student.pop("hobby")      # 删除并返回值
```

**常用方法：**

| 方法 | 作用 |
|------|------|
| keys() | 所有键 |
| values() | 所有值 |
| items() | 所有键值对（遍历常用） |

### 3. 元组和集合

```python
# 元组 - 不可变
coords = (120.5, 30.2)
# coords[0] = 100  # 报错！

# 集合 - 唯一元素
s = {1, 2, 3, 3, 3}  # {1, 2, 3}

# 集合运算
a & b  # 交集
a | b  # 并集
a - b  # 差集
```

### 4. 遍历技巧

```python
# 列表带索引
for i, item in enumerate(list):
    print(i, item)

# 字典键值对
for key, value in dict.items():
    print(key, value)
```
